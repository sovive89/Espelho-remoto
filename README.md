# Espelho Remoto

Aplicativo Android para compartilhamento consentido de tela via WebRTC, com sinalização Socket.IO e visualizador web.

## Estrutura prevista
- `android/`: aplicativo Kotlin e serviço de captura de tela
- `server/`: servidor Node.js e receptor web
- `.github/workflows/android-debug.yml`: build do APK
- `render.yaml`: configuração de hospedagem para demonstração

**Estado:** repositório inicializado. Os arquivos de implementação ainda precisam ser importados do pacote `EspelhoRemoto_Deploy_Android_Preparado.zip`. Nenhum APK foi compilado ou deploy executado.
